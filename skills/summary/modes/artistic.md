# Artistic mode

The page still has to be read in thirty seconds. Design is in service of that, not on top of it.

## Where to look

Pull inspiration from Forever AI Components, a catalogue of zero-dependency single-file components:

- Repo: https://github.com/isas1/forever-ai-components
- Site: https://forevercomponents.com

If you can read the repo, read the index first, then open only the two or three components that fit what this page actually needs. Do not browse the whole catalogue.

If you cannot reach it, work from the house style below.

## How to use a component

- Take the idea and the craft, not the file. Rewrite it inline, trimmed to this page.
- Never add a dependency. Every component there is zero dependency and must stay that way here.
- Two borrowed elements maximum. A page built from five borrowed pieces looks like a demo, not a summary.
- Good candidates: progress and state indicators, stat cards, dividers, section reveals, chart frames, badges.
- Bad candidates: hero animations, decorative backgrounds, anything that competes with the content.

## House style

- Monochrome base. One rationed accent, used to mean something, never for decoration.
- Continuous stroke. Lines that read as one gesture with no visible seam or join.
- Calm loops. Any repeating motion is seamless and slow enough to ignore.
- Restraint reads as quality. Empty space is the design.
- Geist and Geist Mono if the fonts are available locally. Otherwise the system stack. Never load a webfont from a CDN.

## Still true

Everything in the core skill still applies. Self contained, one file, print safe, and the reader's own language. A beautiful page that hides the status has failed.
